## 5. Code Quality Coaching (Non-Scoring)

- **Hardcoded production URL in source**: [api.ts](frontend/src/services/api.ts#L3) contains the Azure production URL as a fallback default. This URL should come exclusively from environment variables to avoid leaking infrastructure details and to simplify environment management.

- **Empty test placeholder**: [UnitTest1.cs](BuckeyeMarketplace.Tests/UnitTest1.cs) contains a `Test1()` method with an empty body. While it passes, it adds no value and should be removed to keep the test suite clean.

- **Missing input validation on backend DTOs**: `CreateOrderRequest`, `CreateProductRequest`, `UpdateProductRequest`, and `UpdateOrderStatusRequest` lack data annotation validation attributes (e.g., `[Required]`, `[MaxLength]`, `[Range]`). While EF Core prevents SQL injection, malformed data could still reach the database.

- **No null-forgiving operator safety**: Multiple controllers use `User.FindFirst(ClaimTypes.NameIdentifier)!.Value` with the null-forgiving operator. If the claim is somehow missing, this throws a `NullReferenceException` instead of returning a meaningful 401/403.

- **JWT stored in localStorage**: [AuthContext.tsx](frontend/src/context/AuthContext.tsx#L32) stores the JWT in `localStorage`, which is accessible to any JavaScript running on the page (XSS risk). While the student correctly avoids `dangerouslySetInnerHTML`, consider using `httpOnly` cookies for token storage in production applications.
